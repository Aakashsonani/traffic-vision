LOCAL FIRST / PYTHON POWERED
KNOW WHAT THE MODEL CAN READ

The sign catalogue.

Distinct meanings, explicit classes. Turn left, keep left, and no left turn stay separate.

Illuminated signals

Red, yellow and green lamps are read separately from their shape: circular, left, right, straight, diagonal, U-turn, pedestrian or cross. Multiple lamps in the same housing remain separate observations.

The sign catalogue combines European and urban model classes. The classifier supports speed limits of 20, 30, 50, 60, 70, 80, 100 and 120 km/h; road-scene detection of each needs evaluation. Painted road arrows and text direction boards are outside this release.

EVIDENCE BEFORE ACCURACY CLAIMS

Measure what matters.

Separate software verification from recognition performance on unseen road scenes.

Run a representative evaluation

Label every supported object in your own road images, including negative scenes. Group images by recording or location before creating train, validation and test splits.

python scripts/evaluate.py --dataset data/evaluation.json --split test

The evaluator matches the exact class and bounding-box overlap. A missed object counts as a false negative; an uncertain result cannot count as a correct recognition.

TRAFFIC VISION / PROJECT NOTES

Built to be understood.

A local Python project for studying traffic sign and signal recognition.

01 / THE PIPELINE

Detect. Decode. Explain.

Two specialist YOLO detectors find road signs. A ResNet classifier verifies sign crops. A COCO detector locates signal housings, and TIER IV classifiers read their colours and arrows.

Every observation includes its bounding box, model score, and meaning. Overlapping contradictory sign predictions are marked uncertain.

02 / THE RUNTIME

Python, on your computer.

FastAPI serves the interface. NumPy and OpenCV prepare images; ONNX Runtime performs CPU inference. After installation and model download, no internet connection or API key is needed.

Camera and video frames are processed one at a time. Uploaded images remain in memory and are not written to disk by the server.

03 / THE BOUNDARIES

Keep the scope honest.

Pretrained models are included through reproducible downloads. This release has not been fine-tuned or validated on your local roads. Unknown designs can still be assigned a familiar class.

Small, blurred, obstructed, or unfamiliar signs need additional data. This project reports observations and does not resolve lane relevance or provide driving decisions.

04 / THE NEXT EXPERIMENT

Improve with evidence.

Collect representative labelled scenes, run the evaluator, and inspect each direction/prohibition confusion. Fine-tune using the training script with image flips disabled.

Version the dataset and weights together. Keep the final test recording separate from training and threshold selection.
